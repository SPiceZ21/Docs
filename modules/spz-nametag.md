# Nametags

> Nametags with rank, crew and record crowns.

> Part of [spz-hud](spz-hud.md): this was the separate resource `spz-nametag` until it was merged in. Nothing to install on its own.

## Overview

Draws a nametag over nearby players with their name, rank, crew and a crown if they hold a track record.

![Nametags in the world](https://raw.githubusercontent.com/SPiceZ21/Docs/main/images/nametag.jpg)

## Features

- Rank and crew tags
- Record crowns
- Distance fade

## Configuration

- `spz-hud/config_nametag.lua (`Config.Nametag`)`

See the file for every option.

## Commands

| Command | Who | Description |
|---|---|---|
| `/syncnametags` | dev | Force a nametag resync |

## Key binds

Rebindable in **Settings → Key Bindings → FiveM**.

| Action | Default |
|---|---|
| Toggle player nametags | `F10` |
